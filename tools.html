Username Checker

Belirli bir kullanıcı adının popüler sosyal medya platformlarında (Instagram, Twitter, GitHub, TikTok, Reddit ve daha fazlası) müsait olup olmadığını kontrol eder. Tarayıcıdan direkt çalışır.

İndir GitHub
Kurulum rehberi
1
Python 3.8+ gerekli: python --version
2
ZIP'i indir ve çıkart.
3
Çalıştır: python usercheck.py
Python OSINT / Telefon
Number Lookup

Bir telefon numarasına kayıtlı sosyal medya hesaplarını sorgular. Hangi platformlara (WhatsApp, Snapchat, Instagram vb.) o numarayla kayıt olunduğunu gösterir. OSINT araştırmalarında kullanılır.

İndir GitHub
Kurulum rehberi
1
Python 3.8+ gerekli.
2
git clone https://github.com/megadose/ignorant.git
3
cd ignorant && python3 setup.py install
4
Kullanım: ignorant [ülke kodu] [numara]
Örnek: ignorant 90 5001234567

GitHub

2
